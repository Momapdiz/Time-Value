TIME VALUE — PWA MVP
1) Upload the contents of this folder to a public HTTPS static host (GitHub Pages is a free option).
2) Share the published HTTPS URL with friends.
iPhone: open URL in Safari > Share > Add to Home Screen > Add.
Android: open URL in Chrome > menu ⋮ > Install app / Add to Home screen.
Features: intentional session timer, manual useful-time logs, daily target, weekly totals, CSV export.
Privacy: data is stored locally in this browser/device; it is not synced between devices or shared with the publisher.
Limitations: does not automatically read iOS Screen Time or Android Usage Stats. Manual logging only.
For updates, replace uploaded files on hosting; users may need to reopen/refresh the app.
